Cursor ocupado
KDE ofrece un cursor ocupado para la notificación de inicio de la aplicación. Para activar el cursor ocupado, seleccione un tipo de respuesta visual en el cuadro combinado. Puede ocurrir que algunas aplicaciones no tengan conocimiento de esta notificación de inicio. En este caso, el cursor deja de parpadear una vez transcurrido el tiempo indicado en la sección «Tiempo de espera de la indicación de inicio»

Para que la representación de subpíxeles funcione correctamente, necesitas saber cómo están alineados los subpíxeles de la pantalla. En las pantallas TFT o LCD, un solo píxel está compuesto en realidad por tres subpíxeles: rojo, verde y azul. La mayoría de las pantallas tienen un orden lineal de subpíxeles RGB, mientras que algunas tienen BGR. Esta función no funciona con los monitores CRT.

Forzar el DPI de las fuentes:
96 DPI
120 DPI
Esta opción impone un valor de DPI específico para las fuentes. Puede resultar útil cuando los DPI reales del hardware no se detectan correctamente y también se suele utilizar de forma incorrecta cuando se utilizan fuentes de mala calidad que no se ven bien con valores de DPI distintos de 96 o 120 DPI. Por lo general, se desaconseja el uso de esta opción. Para seleccionar el valor de DPI adecuado, una mejor opción es configurarlo explícitamente para todo el servidor X si es posible (por ejemplo, DisplaySize en xorg. conf o añadir el valor -dpi a ServerLocalArgs= en $KDEDIR/ share/ config/ kdm/ kdmrc). Cuando las fuentes no se renderizan correctamente con un valor real de DPI, se deben utilizar fuentes mejores o se debe comprobar la configuración de las sugerencias de fuentes.
