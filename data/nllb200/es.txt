Esta opción obliga a un valor DPI específico para las fuentes. Puede ser útil cuando el DPI real del hardware no se detecta correctamente y también se usa a menudo cuando se usan fuentes de mala calidad que no se ven bien con valores DPI distintos de 96 o 120 DPI. Generalmente se desalienta el uso de esta opción. Para seleccionar el valor DPI adecuado, una mejor opción es configurarlo explícitamente para todo el servidor X si es posible (por ejemplo, DisplaySize en xorg. conf o agregar valor -dpi a ServerLocalArgs= en $KDEDIR/share/config/ kdm/ kdmrc). Cuando las fuentes no se renderen correctamente con el valor DPI real, se deben usar mejores fuentes o verificar la configuración de la sugerencia de fuente.
