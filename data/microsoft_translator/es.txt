Esta opción obliga a establecer un valor DPI específico para las fuentes. Puede ser útil cuando el DPI real del hardware no se detecta correctamente y también se utiliza a menudo cuando se usan fuentes de mala calidad que no quedan bien con valores de DPI distintos de 96 o 120 DPI. El uso de esta opción generalmente está desaconsejado. Para seleccionar el valor DPI adecuado, una mejor opción es configurarlo explícitamente para todo el servidor X si es posible (por ejemplo, DisplaySize en xorg. conf o añadir el valor -dpi a ServerLocalArgs= en $KDEDIR/ share/ config/ kdm/ kdmrc). Cuando las fuentes no se renderizan correctamente con el valor real de DPI, se deben usar mejores fuentes o comprobar la configuración del hinting de fuentes.
