Seleccione si la programación en tiempo real debe estar habilitada para la aplicación. El programador gobierna qué procesos se ejecutarán y cuáles tendrán que esperar. Hay dos programadores disponibles: Normal: Este es el programador estándar, de tiempo compartido. Divide equitativamente el tiempo de procesamiento disponible entre todos los procesos. Tiempo real: Este programador ejecutará su aplicación sin interrupción hasta que abandone el procesador. Esto puede ser peligroso. Una aplicación que no abandone el procesador podría colgar el sistema. Necesita la contraseña de root para usar el programador.

Esta opción obliga a un valor de DPI específico para las fuentes. Puede ser útil cuando el DPI real del hardware no se detecta correctamente y también se usa a menudo de forma incorrecta cuando se usan fuentes de mala calidad que no se ven bien con valores de DPI distintos de 96 o 120 DPI. El uso de esta opción generalmente se desaconseja. Para seleccionar el valor de DPI correcto una mejor opción es configurarlo explícitamente para todo el servidor X si es posible (por ejemplo, DisplaySize en xorg. conf o añadiendo el valor -dpi a ServerLocalArgs= en $KDEDIR/ share/ config/ kdm/ kdmrc). Cuando las fuentes no se representan correctamente con el valor de DPI real se deberían usar fuentes mejores o comprobar la configuración de las sugerencias de fuentes.
